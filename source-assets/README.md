# Source assets / 源素材

## Files

- `spritesheet.png`：完整无损 RGBA 总图，`1536 × 2288`。
- `gaze-directions/*.png`：从总图最后两行无损裁切出的 16 张透明方向帧，每张 `192 × 208`。

方向编号从 `000°` 开始，每次顺时针递增 `22.5°`：

```text
000°, 022.5°, 045°, 067.5°, 090°, 112.5°, 135°, 157.5°,
180°, 202.5°, 225°, 247.5°, 270°, 292.5°, 315°, 337.5°
```

这里的 16 张图片是视线/朝向素材，不代表安装包实现了普通系统鼠标的全局跟随。当前项目不包含鼠标监听代码；方向帧是否被使用由宿主客户端决定。

安装桌宠时不需要复制本目录，只需使用 `pet/chibi-aigis-baby-dance/` 或 Release ZIP。
